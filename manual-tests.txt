# Module 5: Application closing after window closed request

## Test Steps
1. Build and run CiCo.
2. Make sure that CiCo loads up properly.
3. Press the X in the top right corner to close CiCo.

## Expected results
* Should properly close out of CiCo
* Should allow for CiCo to boot up after the closing as normal.

# Module 5: Automatically submit card number

## Test Steps
1. Build and run CiCo.
2. Enter 00000000 into the card number field without pressing Enter or clicking Update.

## Expected results
* The card number should automatically be submitted after the eighth digit is entered.
* The check-in process should begin without requiring the user to press Enter or click Update.
